# Release Scope

This repository collects CFLLM research artifacts for
RQ1, RQ2, RQ3, and benchmark evaluation.

RQ1 reuses the methodology of previous ECC research.
The complete CFLLM-specific RQ1 analysis workflow
has not yet been released.

RQ2 includes training configuration templates and
related experimental scripts. The original full
25/50/75 data-construction program has not been
identified.

RQ3 includes candidate generation, static screening,
and dataset construction scripts.

Some experimental and evaluation scripts retain
environment-specific paths.

This repository should not currently be described as
a fully verified end-to-end reproduction package.
