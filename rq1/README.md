# RQ1: Empirical Analysis of Code Cleanliness

RQ1 investigates function-level code cleanliness evolution
in Python and C++ open-source projects.

Three structural metrics are considered:

- Cyclomatic Complexity (CC)
- Function Length (Rows)
- Number of Parameters (Args)

## Relationship to Prior Work

The repository mining and historical code collection
methodology builds upon our previous work:

Dapeng Yan et al.,
"Evolving Trends in Cleanliness of Open Source Projects,"
ACM Transactions on Software Engineering and Methodology,
2026.

The prior work provides the foundation for mining
repository histories and analyzing code evolution.

The CFLLM study focuses on Python/C++ function-level
cleanliness and its implications for language model
adaptation. Its corpus selection and experimental
procedures should be distinguished from those of
the previous study.

## Reproducibility

The historical collection methodology is documented
in the prior work. CFLLM-specific function pairing,
metric aggregation, and analysis artifacts will be
documented separately as they are verified.
